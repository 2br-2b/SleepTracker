# Sleep Tracker

An Android application to track your sleep patterns and integrate with Health Connect.

## Features

*   **Automatic Sleep Tracking:** The app automatically detects when you go to sleep and wake up by monitoring your phone'''s screen lock and unlock events.
*   **Health Connect Integration:** Securely stores your sleep data in Health Connect.
*   **Data Visualization:** Provides a user-friendly interface to view your sleep history.
*   **Customizable Sleep Window:** Allows you to define your typical sleep hours to improve detection accuracy.

This project is built with modern Android development in mind, using Jetpack Compose for the UI and the Health Connect API for health data management.
